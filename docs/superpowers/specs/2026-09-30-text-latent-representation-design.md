# Text-to-Latent Representation Notebook Design

## Goal

Improve `applied_machine_oil/lab3/Text_to_Latent_Representation_.ipynb` into a complete, reproducible teaching notebook for transforming customer reviews into token IDs, padded sequences, trained word embeddings, flattened sentence vectors, and a two-dimensional PCA visualization.

## Scope

The notebook will use the five reviews from the assignment:

- “The product quality is excellent”
- “I really love this product”
- “The quality of this item is amazing”
- “The product performance is poor”
- “I dislike this product completely”

The reviews will have explicit binary sentiment labels derived from the supplied examples: the first three are positive and the last two are negative. The labels are used only to make the small embedding model trainable and to explain how supervised learning updates the embedding matrix; they are not presented as a statistically meaningful sentiment benchmark.

## Notebook structure

1. **Assignment overview and enhancement checklist**
   - State the objective and data flow.
   - List every additional learning item added beyond the reference notebook.
   - Explain that token IDs are categorical indices, not meaningful numeric magnitudes.
2. **Imports and reproducibility**
   - Use NumPy, pandas, Matplotlib, TensorFlow/Keras, and scikit-learn PCA.
   - Set Python/NumPy/TensorFlow seeds and print runtime versions.
3. **Dataset and preprocessing**
   - Display the review/label table.
   - Normalize case and punctuation using a small transparent preprocessing helper.
   - Show before/after text and token counts.
4. **Vocabulary and tokenization**
   - Fit a Keras tokenizer on cleaned text.
   - Display a sorted word-to-token-ID table, including the reserved padding ID `0`.
   - Display each review as a variable-length sequence of IDs.
5. **Padding**
   - Derive `max_length` from the longest sequence rather than hard-coding it.
   - Apply post-padding with `0`.
   - Display a review/sequence table and assert uniform shape.
6. **Embedding model**
   - Build a small Keras model with an embedding layer, pooling/flattening path, and binary classifier.
   - Use a seeded training run with bounded epochs and quiet output.
   - Explain the embedding tensor shape `(samples, sequence_length, embedding_dimension)` and the padding row.
7. **Embedding extraction and inspection**
   - Extract the learned vocabulary embedding matrix.
   - Display each word and its fixed-dimensional vector in a formatted table.
   - Display each sentence’s embedding matrix, retaining sequence order and padded zero rows.
   - Include a shape/value check showing that each token ID selects one row from the embedding matrix.
8. **Flattened sentence vectors**
   - Flatten each sentence matrix into one vector.
   - Display the resulting table and verify `sequence_length × embedding_dimension` features per review.
   - Explain that flattening preserves position but increases dimensionality and is not the same as semantic pooling.
9. **PCA visualization**
   - Reduce non-padding word embeddings to two components with scikit-learn PCA.
   - Plot and annotate each vocabulary word.
   - Report explained-variance ratios and interpret proximity cautiously because the dataset is tiny and embeddings are learned from limited supervision.
10. **Conclusions and limitations**
   - Summarize the complete transformation pipeline.
   - Distinguish learned latent representations from pretrained language-model embeddings.
   - Note small-data overfitting, random initialization, padding, and the limitations of interpreting PCA distances.

## Technical decisions

- Use deterministic preprocessing and `Tokenizer` behavior so token IDs are reproducible.
- Reserve token ID `0` for padding and set `mask_zero=True` on the embedding layer so padding does not influence pooled representations.
- Use a fixed embedding dimension of 8: large enough to make the multidimensional representation visible while keeping the flattened vectors easy to inspect.
- Use global average pooling for the classifier’s sentence representation, then separately use the full embedding sequence for the required flattening operation. This avoids treating the flattened vector as the classifier’s learned decision input.
- Use PCA only on actual vocabulary-word rows, excluding the zero padding row.
- Keep all outputs generated by notebook cells rather than relying on stale reference outputs.
- Avoid external pretrained-model downloads so the notebook runs offline in the parent environment’s `venv`.

## Validation criteria

- The vocabulary table contains every unique normalized word exactly once, with unique positive IDs and an explicit padding row.
- Every review converts to the expected token sequence and all padded sequences have one common shape.
- The embedding tensor has shape `(5, max_length, 8)`, and the extracted word matrix has shape `(vocab_size + 1, 8)`.
- The padding row remains all zeros when masking is enabled.
- Each flattened review vector has exactly `max_length * 8` values.
- PCA produces two coordinates for every non-padding vocabulary word and reports two explained-variance ratios.
- The notebook executes end-to-end in the parent `venv` without network access or hidden files.
