Lab 9 — Support Vector Machine (SVM) & Principal Component Analysis (PCA)

Aim: Implement SVM for classification and PCA for dimensionality reduction, and analyse their effectiveness on real-world datasets. Supervised (SVM) vs unsupervised (PCA) learning are contrasted; class balancing and stratified k-fold cross-validation are applied throughout.

Part A — Support Vector Machine (SVM)

Dataset: UCI Breast Cancer Wisconsin (Diagnostic) — 569 samples, 30 features. Features standardized (SVM is distance-based).

Class distribution

Mild imbalance: malignant 212 vs benign 357.

Method

  • 80:20 train/test split with stratify=y (preserves class ratio).
  • Class balancing via class_weight='balanced' to stop the minority (malignant) class being ignored.
  • Hyperparameter tuning of C by GridSearchCV over a log range with 5-fold stratified k-fold CV, selecting the best CV F1.
  • Kernel comparison: linear / rbf / poly.

Part B — Principal Component Analysis (PCA)

Dataset: UCI Wine — 178 samples, 13 features (3 cultivars). Features standardized so no single variable dominates the variance.

PCA projection & explained variance

2-D PCA projection of Wine; PC1 = 36.2% variance, PC2 = 19.2% (total 55.4% retained in 2 PCs).

Variance retained & minimum components for ≥ 95%

The cumulative curve crosses 95% variance at 10 of 13 components — a strong compression: from 13 dimensions down to 10 keeps essentially all information.

PCA pros: decorrelates, denoises, compresses, speeds models, enables 2-D visualization. Cons: loses variance, components are harder to interpret, scale-sensitive, unsupervised (ignores labels). Applications: preprocessing, denoising, eigenfaces, visualization, factor analysis.

Extra credit — Linear Discriminant Analysis (LDA)

LDA explained-variance ratio: [0.6875, 0.3125] (total 100.00%). LDA is supervised — it uses class labels to maximize separation, so the three cultivars form tighter clusters than in PCA. Trade-off: LDA needs labels and is limited to C-1 = 2 components for 3 classes.

Conclusions

  1. SVM (supervised): linear SVM with class_weight='balanced' handled the mild imbalance; stratified k-fold CV confirmed stable generalization; kernel chosen by CV F1 (winner: rbf).
  2. PCA (unsupervised): reduced Wine 13→2 retaining 55.4% variance; only 10 components needed for ≥95% variance — strong compression.
  3. Supervised vs unsupervised: SVM uses labels to classify; PCA ignores labels and only compresses variance. LDA (extra credit) uses labels and yields tighter class clusters than PCA in 2-D, at the cost of needing labels and fewer components.

All results use random_state=42, class_weight='balanced', and stratified 5-fold CV for reproducibility.
