### Task 6: Hyperparameter tuning (C) with stratified k-fold CV
**Objective:** Grid-search the `C` regularization parameter using stratified CV.

**Markdown cell 9:**
```
### 5. Hyperparameter Tuning — GridSearchCV on C (Stratified K-Fold)
`C` controls the trade-off between a wide margin (small C, more tolerant of
misclassification) and a narrow margin (large C, fewer errors). We search over
a log-spaced grid with 5-fold stratified cross-validation.
```

**Code cell 6:**
```python
param_grid = {'C': np.logspace(-3, 3, 13)}   # 1e-3 ... 1e3

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
gs = GridSearchCV(
    SVC(kernel='linear', class_weight='balanced', random_state=42),
    param_grid, cv=cv, scoring='f1', n_jobs=-1
)
gs.fit(X_train, y_train)

print(f'Best C: {gs.best_params_["C"]:.4f}')
print(f'Best mean CV F1: {gs.best_score_:.4f}')

best_svm = gs.best_estimator_
y_pred_best = best_svm.predict(X_test)
report(y_test, y_pred_best, f'Linear SVM — tuned C={gs.best_params_["C"]:.4f} (balanced)')
```

**Markdown cell 10 (Inference):**

### Task 12: Cumulative variance + min components for ≥95%
**Objective:** Fit full PCA, compute cumulative variance, find n for ≥95%.

**Markdown cell 20:**
```
### 3. Cumulative Variance & Components Needed for ≥95%
```

**Code cell 11:**
```python
pca_full = PCA(random_state=42).fit(Xw_s)
cum_var = np.cumsum(pca_full.explained_variance_ratio_)
n_95 = int(np.argmax(cum_var >= 0.95) + 1)

print('Cumulative explained variance by #components:')
for i, c in enumerate(cum_var):
    print(f'  {i+1:2d} PCs: {c*100:6.2f}%')
print(f'\nMinimum components to retain >=95% variance: {n_95}')

plt.figure(figsize=(7, 4))
plt.plot(range(1, len(cum_var)+1), cum_var*100, 'bo-')
plt.axhline(95, color='r', linestyle='--', label='95% threshold')
plt.axvline(n_95, color='g', linestyle='--', label=f'{n_95} components')
plt.xlabel('Number of Principal Components')
plt.ylabel('Cumulative Explained Variance (%)')
plt.title('PCA — Scree / Cumulative Variance (Wine)')
plt.legend(); plt.grid(True)
plt.show()
```

**Markdown cell 21 (Inference):**
```
The scree plot shows the elbow; `n_95` components are needed to keep ≥95% of the
information — far fewer than 13, demonstrating PCA's compression power.
```

### Task 16: LDA → 2 discriminants + overlay vs PCA
**Objective:** Fit supervised LDA to 2 components and compare class separability.

**Markdown cell 27:**
```
### Extra Credit — Linear Discriminant Analysis (LDA)
LDA is *supervised*: it finds axes that maximize class separation (between-class
variance / within-class variance), unlike PCA which only maximizes total variance.
```

**Code cell 14:**
```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

lda = LinearDiscriminantAnalysis(n_components=2)
Xw_lda = lda.fit_transform(Xw_s, yw)

plt.figure(figsize=(7, 5))
for idx, name in enumerate(wine_targets):
    m = yw == idx
    plt.scatter(Xw_lda[m, 0], Xw_lda[m, 1], c=colors[idx], label=name, s=40, alpha=0.8)
plt.xlabel('LD1')
plt.ylabel('LD2')
plt.title('Wine — LDA 2-Discriminant Projection')
plt.legend(); plt.grid(True)
plt.show()

print(f'LDA explained variance ratio: {lda.explained_variance_ratio_}')
print(f'Total LDA variance retained: {lda.explained_variance_ratio_.sum()*100:.2f}%')
```

**Markdown cell 28 (Inference):**
```
LDA typically separates the 3 cultivars MORE cleanly than PCA in 2-D because it
uses class labels. Trade-off: LDA needs labels and is limited to (C-1)=2 components
for 3 classes, while PCA is label-free and can keep more components.
```
